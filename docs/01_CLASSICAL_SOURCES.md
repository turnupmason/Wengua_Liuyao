## 一、入库原则

- 只收明清及以前古籍的**原文**。现代白话改写、点校者注释、网站解读放在研究项目 `D:\Wengua_LLM\sources\modern\`，**不复制、不作出处**。
- 每部书记录：来源网站、抓取日期、首章网址、维基文库修订号（如有）、原始抓取件 SHA-256、入库清洗本 SHA-256（LF 换行）。
- 网络转载的一句话不能直接当原文：每条规则的 `original_text` 由 `npm run verify:rules` 在所注卷章内逐字核对（去除标点空白后为连续子串），不在所注章节即构建失败。
- 本轮没有拿到纸本或影印善本，**所有版本都是网络录入本**。凡录入本自身的错字、缺文，记入校勘表，不擅自改动原文文件。

## 三、原文、异文、解释的区分

规则登记表每条有 `adoption` 字段：

- `adopted`：本项目采用，进入程序或断语判断；
- `alternative`：与采用口径不同的另一家说法，事实层同列，断语遇到须说明；
- `reference`：互校或背景，不参与判断；
- `not-adopted`：明确不采用（附理由，如野鹤「用神不现即再占」与一问一卦的产品形态冲突）。

历史作者的解释（如野鹤「予试之不验」、王洪绪注、李我平按语）与原文一样逐字引用，但在 `modern_explanation` 中注明是谁的观点；本项目自己的补充（如「旺相」在区分暗动与日破时的取法）写在 `applicable_conditions` / `exceptions`，并在分歧表登记，不冒充古籍原话。
