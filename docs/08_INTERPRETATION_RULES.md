# 08 原忌仇神、飞伏、冲合墓绝及综合断案

## 一、固定流程

起卦 → 装卦 → 取用神 → 日月旺衰 → 原忌仇神 → 动爻变爻 → 世应与飞伏 → 空破墓合冲 → 综合判断 → 应期 → 自然中文。

程序负责第一层（卦象事实）与证据清单；第二至第四层（主要吉凶条件、证据冲突、最终判断）由作者写入作者源稿的 `judgment`，包括 `deciding_evidence`、`supporting`、`adverse`、`conflicts_resolved` 与所依规则编号；第五层才写正文。程序不自动下吉凶结论。

## 二、原神、忌神、仇神（R-YUANJICHOU-01、R-YUANJI-01..05）

生用神者原神，克用神者忌神，克原神而生忌神者仇神。五行关系存在不等于实际起作用，`buildEvidence()` 对每个原神、忌神逐条列出增删卜易元神忌神衰旺章的条件：

- 原神有力五条：旺相或临日月或得日月动爻生扶；动化回头生或化进神；长生帝旺于日辰；与忌神同动；旺动临空化空。
- 原神无力六条：休囚不动或动而受伤；休囚又逢空破；休囚化退；衰而又绝；入三墓；休囚化绝化克化破。
- 忌神有力五条、无力七条同理（第二条文义存疑，见 D-011）。
- 前提：「亦要用神有气，倘若用神无根谓之元神有力亦难生」（R-YUANJI-05）。

另列 `actsOnYong`：发动、暗动或安静。静爻原则上不主动作用于他爻，只有旺相静爻可生克休囚之爻（R-DONGJING-01）。不得无限串联五行关系制造作用链。

## 三、飞伏（R-FUSHEN-01..05）

伏神有用六条、终不得出五条逐条判真假；飞伏关系（飞来生伏、飞克伏、伏克飞等）单列。两类条件可能同时成立，须由作者权衡并在断语中说明。

## 四、冲合墓绝

- 六合：静爻逢合为合起，动爻逢合为合绊（R-HE-01）；「然必用神有气相宜，用若失陷无益」。
- 六冲：「必兼用神而言，用神旺虽冲不破」（R-CHONG-01）。
- 三墓只看日墓、动墓、化墓（R-SANMU-01）；入墓不等于现实中的死亡或失去机会。
- 生旺墓绝只用四位，土随水长生于申（R-SWMJ-01/02，分歧 D-004）。
- 三刑、六害只列事实，不单独定吉凶（R-XING-01、R-HAI-01，D-007）。
- 反吟伏吟主反复，「用神旺相不变冲克者虽则反复，事之必成」（R-FANFU-01）。

## 五、综合判断

- 四处生克（R-SICHU-01）：月建、日辰、动爻、自身动化四处对用神的生克合看；生多克少为吉；生克相当时看双方旺衰；「相生之爻休囚者有生之名无生之实」。
- 克处逢生（R-KECHU-01）。
- 证据冲突必须在 `conflicts_resolved` 中写明取舍依据。本轮样稿中的冲突示例：
  - IP-0002：官星有气而忌神持世发动有力——依四处生克取凶，并排除黄金策「福德变官身位合」例外；
  - IP-0003：官星季节休囚而得日生、动生、化进——依广义之旺取吉；
  - IP-0006：官星临日帝旺而化出月建子孙回头克、化绝——以「动为始、变为终」取变爻定结局。

## 六、判别流程（第二轮，`src/flows.js`）

| 流程 | 步骤 | 依据 |
|---|---|---|
| 飞伏 `assessHidden` | 伏神有无气 → 有无终不得出之阻 → 飞神是否被推开（空破休囚墓绝、被日月动爻冲克）→ 有无生扶 → likely / contested / unlikely；飞伏生克按卜筮正宗歌诀命名；飞神空破而克伏者「虽有若无」 | R-FUSHEN-02/03/06/07/08 |
| 旬空 `assessVoid` | 冲空则实 → 空而又破 → 真空 → 有气之空（列出冲空日、填实日距起卦日的天数及是否在本旬内）→ 静空无助 | R-KONG-02..06、R-YINGQI-08 |
| 月日相敌 `assessMonthDay` | 临月建而墓于日或受日冲克：无吉无凶，待他爻动扶动克；临日而受月克月破：逢破不破、遇克无伤，但再有动克或本爻动化相克则寡不敌众 | R-YUEJIAN-04、R-RIZHEN-05 |
| 动化 `assessChange` | 回头克：克神空破受冲克则克力不实；本爻临月建则逢伤待时；本爻只临日又受月克则寡不敌众；其馀化凶。回头生：生神空破则打折 | R-HUA-01/02、R-YUEJIAN-03、R-RIZHEN-05 |

伏藏原神受忌神动生能否接续相生，书中只见两神俱动之例，列为 D-013，本版只作转机条件。作者须在 `judgment.flow_acknowledgements` 中逐项确认或说明不采用的理由（构建检查 C17）。

## 七、D-015 三层判定（第三轮，`src/role-state.js`）

| 层 | 内容 | 依据 |
|---|---|---|
| 一、月令旺衰 | 增删卜易三档（旺、相、休囚）为判断用；通行五级（旺相休囚死）只作标签（古籍库未见定义原文）。不因日辰生扶改写 | R-WANG-01 |
| 二、综合作用能力 | 月建、日辰、卦中动爻、自身动化四处逐处记生克：有生无克、生多克少为有力；有克无生为无力；生克相当看双方是否为日月；克多生少而生者为日月则待核。爻临日辰另依日辰章（遇克无伤，但动克或动化相克则寡不敌众）；临月建而受日克冲墓依月将章（月日相敌） | R-SICHU-01、R-RIZHEN-05、R-YUEJIAN-04 |
| 三、当前作用状态 | EFFECTIVE：有力且无受限；DEFERRED：有力而受旬空、静而月破、或休囚入墓之一，记明待冲空/填实/逢合/冲墓之支与日数；INEFFECTIVE：无力，或休囚受克又入墓（真墓）；REVIEW_REQUIRED：生克相当无从裁决，或空破墓并见。动而月破为有效（动则能伤）；月令旺相之墓不作真墓 | R-KONG-02、R-YUEPO-02、R-SUIMU-01 |
| 四、能否作用于用神 | 发动、暗动可主动作用；静爻须月令旺相，且只及于休囚之爻；静而休囚之爻不主动作用 | R-DONGJING-01 |

元神忌神衰旺章的有力、无力条文原样核对（「休囚」取月令），条文之间的冲突由三层判定裁决。回归测试见 `tests/role-state.test.mjs`。

## 八、规则改动

任何规则改动都会改变事实指纹（`facts_digest`）。已写稿件的指纹不符时，构建报告会显示，查询接口自动退回「本卦断语尚在整理」，须重新复核后才能再次批准。改动前应跑全部测试并在 14_PROGRESS.md 记录影响范围。
