## 二、忌神（子孙）、原神（妻财）

- **忌神**：
  - 忌神与元神同动：用神有根者，「忌神虽动，不能克用神者…忌神与元神同动七也」（R-YUANJI-04），接续相生，化凶为吉；用神无根者，「元神有力亦难生」（R-YUANJI-06 原例），仍判不利（IPC-0298、IPC-0308）。
  - 用神有气而旬空（`[DEFERRED旬空]`）、忌神与元神皆动而有力者：接续相生成立，眼下待出空，判眼下悬而未决、出空后有望（IPC-1027）。
  - eq-0.12.4 起，忌神「动有力」而原神最强一爻不是发动之爻、另有一爻原神发动时，类键加「忌元同动(原…)」，括号内是发动之原神自身的作用状态。原键未分此项，IPC-0241、0386、0408、0467、0480、0481、0485、0503、0519 及第 569 类曾把同动与不同动之盘并在一类；拆分后各按新类内容改稿。同动而发动之原神旬空待时者，从 IPC-0480 之理判有望而待时；原神静而另无同动者，从八宫图「被卦中子孙发动以伤官」判偏难。
  - 「动有力」「暗动有力」为主要不利依据（C22）。
  - 「静旺有力」只能克休囚之爻（R-DONGJING-01）。忌神旺相时，月建必为子孙或兄弟之五行，官星必休囚，所以静旺之忌神总能克到官星，属不利，但弱于发动。
  - 「伏有效」作潜在不利，不作主要依据。
  - 「伏待时」「伏难出」「静不作用」「无力」「待时（旬空）」不构成威胁。
- **原神**：
  - 「动有力」为最强之助（「财动生官得美缺」，R-YONG-GUAN-03）。
  - 「静旺有力」只对休囚之官有生扶之用；官星不休囚时不另计（IP-0002、IPC-0003 之例）。
  - 「伏有效」为一线转机，不作翻判依据（D-013）。
  - 其余不计。
- **原忌皆静而旺相**（月建为子孙之五行）：克者旺于生者，「克用神之神旺相者可以凶推」（R-SICHU-01）。

## 三、世爻

- **持世**：见上。
- **世安**：不另计。
- **世受克**：「世爻受制，岂宜自己之谋」（R-SHIYING-03），为次要不利。
- **世空、世破**：
  - 「世空世破官破官空，俱不得」（R-YONG-GUAN-07）；「官空世破，且让他人」（R-YONG-GUAN-04）。
  - 世破一般判偏难。
  - 世空：类推 D-017 的口径，世爻有气而空者作待时，无气而空者从「俱不得」。
    - eq-0.12.2 起指纹把世空分为「世空有气」（世爻三层判定非无力，作待时）与「世空无气」（世爻三层判定无力，从「俱不得」），同类之内不再混杂。
  - 世破：月破之论依野鹤（D-006）「目下虽破，出月则不破」，正文须写明破只管当月；类内世爻有气、无气混杂时仍从专章判偏难。
  - 世破而世爻全类有气（三层判定待时，非「静而不动又无日辰动爻生助」之到底破，R-YUEPO-02）者，类推世空有气，作待时（有望而待时），正文写明出月、填实、逢合之日可复（IPC-0304 起）。
  - 结论以「世空世破」为主要不利依据时，判断记录写 `decisive: [{role: world, effect: adverse, basis: 空破}]`（C33 逐盘核对世爻确空或确破）。
- **世…子孙（子孙持世）**：「子孙持世且待时」（八宫图）、「子孙持世，休望荣荫」（升选章）、「子孙持世而失望」（序）。
  - 忌神有力时判偏难。
  - 忌神无力时，从八宫图「且待时」判待时；类推，正文须写明「持世的子孙本身无力」。
- **世化吉、世化凶、世动**：
  - 「世化退神…必无勇往之心」（乡试章，R-SHIHUA-01）：化凶为次要不利。原文只言化退；化回头克、化绝、化墓为程序类推，正文须分别说明。所化兼回头生与化绝者（如土化巳火），吉凶相杂，只作次要因素。
  - 化吉为次要有利。
  - 世动：主动之象，不另计吉凶。

## 四、卦级

- **六合**：「凡得诸合，诸占皆以为吉」，但须用神有气，且官父世得地（R-HE-01、R-HE-02）。用神有气时加强有利；用神无力时「虽六合亦无益」。
- **六冲**：「冲者散也…占吉事而不宜，必兼用神而言，用神旺虽冲不破，用神失陷凶而又凶」（R-CHONG-01）。
  - 用神有气：结论不翻，但须写明事有散意、易生波折。
  - 用神无力：加重不利。
- **变合**（六冲卦变六合）：「占功名始则艰驻，终顷荣显」（六合章，底本如此，「驻」「顷」疑为「阻」「倾」）。其余变出六合者，作后段有合之象。
- **合变冲**：「先合后离…始荣终悴，得而复失，成而后败」（六合章、六冲章），为后段不利。
- **反吟、伏吟**：反复、迟滞（R-FANFU-01）。用神旺相不变冲克者「虽则反复，事之必成」。

按 D-020 与 R-SANHE-01..06，见 docs/06。吉局待成者，取 R-SANHE-03/04 作待时之期；凶局作防范之时。

## 六、应期

只写**全类每一盘都有候选**的规则（`reports/class-profiles-*.json` 的 timing_rules_all_charts）。没有全类通用的规则时，应期栏只写说明、不列条目（docs/09「没有依据时应期栏可以只写说明」），不得写出只对部分盘成立的日子。

## 七、结论类别

| 类别 | 何时用 |
|---|---|
| 倾向通过（likely-pass） | 用神有气且无有力之克，或有原神动生 |
| 有望通过但要待时（pass-but-slow） | 有利而有明确的慢因：休囚化进神、伏而有用、子孙持世而无力、六冲有散意等 |
| 悬而未决，待时有望（wait-then-likely） | 用神有气而旬空、伏而待时 |
| 偏难通过（unlikely） | 用神无力、伏难出、化凶，或忌神有力而克，或世破、子孙持世而忌神有力 |
| 成败未定（undetermined） | 有利、不利证据势均而无规则可定者；须写明理由，慎用 |
