## 〇〇、2026-11-15 第三版：官父并看（面试问，优先于第〇节及以下各节）

起因：9 个外部现代卦例的盲测（`reports/held-out-cases-interview.md`）里，只看官鬼的现行断法错了 4 例，错处集中在三点：不看父母、把「官无情」当作单独判据、官持世不问旺衰。逐条对照《增删卜易》功名诸章，发现考试类本来就是官父并看。复盘与检验见 `reports/interview-v3-review-2026-11-15.md`。取舍记为 D-023。

**适用**：面试、笔试、考核、选拔类求职，用童试、岁科考、考道才、乡试、武试诸章（「文试者，官父而重」，R-QIUMING-15）。升职、内调、补缺、保官仍用升选候补章与第〇节。

### 1. 三层问题，断语逐层回答

| 层 | 主看 | 依据 |
|---|---|---|
| 面试、笔试一关（临场表现、分数、文书） | 父母为主，世爻为自身 | R-QIUMING-03、05、06、07 |
| 能否被录取 | 官鬼为主，父母为辅 | R-QIUMING-08「父衰官旺堪许登科」「父旺官衰终须下第」；R-QIUMING-03「官衰父发，亦论抡收」 |
| 录取后成不成行 | 子孙持世、父或世临玄武、化空、入墓 | R-QIUMING-10；例 1「能录用而未必去」 |

用神取法：官、父各自按明现、伏神、化出、日月来取（第〇节第 4 条、R-FUSHEN-01）。官父有一不上卦，看伏神，伏而旺相或飞神被冲去者可成（R-QIUMING-14）。

### 2. 否决：任一条成立，判偏难

1. **子孙发动或暗动克官**（R-QIUMING-04、R-QIUMING-10；例 4、6、8）。例外：
   - 官临日辰，为令星（R-LINGXING-01；例 9）。
   - 子孙合入生官、生世之局，贪生忘克（R-QIUMING-13、R-SANHE-07；例 9）。
   - 子孙动而化回头克（R-YUANJI-04）。
   - 子孙与财同动，接续相生（R-YUANJI-04）。
   - 子孙化退神而无原神同动生它（R-BZZ-LI-01，同人之革例）；子孙无力（R-YUANJI-04）；子孙动而被日辰合住，待冲开之时（R-BZZ-LI-01）。
   - 合入生官之局，已成或待时都算（增删·艮之颐例「喜申子辰合成水局以生官，不独无害」，R-SANHE-07）。
   - 官临月建**不再免克**（D-023，例 6）。易林补遗「月临官鬼谁怕子兴」记为异说。
2. **财发动克父**（R-QIUMING-04「财动克父」）。例外：财生官、官又生父或生世，是接续相生（R-QIUMING-06 岁考例；例 7）；父旺不受克。
3. **父母无力或动而变凶**：父母空破墓绝而静，「他不见用」（R-QIUMING-07；例 3、8）；父母动而化回头克、化真空、化退神，「场中一日短」（R-QIUMING-05；例 2）。例外：官旺而持世或生世者，父衰不碍（R-QIUMING-08「父衰官旺」）；化出之爻旬空而非真空者作待时（D-017）。
4. **世爻失位**：世月破又受克（R-YUANLI-01）；世空而无气；日月冲克世而无扶（R-QIUMING-11）。世受日月冲克而有扶，扶是另一方日月、动爻生扶或应爻生合，按「世爻受克而有扶，亦业姑许」（R-QIUMING-06）。
5. **官克世**：面试、求职是「尚未见用而问收用」，「官爻克世及空破者不禄」（R-ZS-QM-02），「官宜生身，不宜克世」（R-QIUMING-06），「最怕官爻克世」（R-ZS-QM-06）。不再按升选章「世旺者竞升」（D-025）。例外：官生动父、父生世，贪生忘克（R-YUANJI-06，增删·蹇之需例）。
6. **官临应、官生合应而不就世，父也不就世**：「官临应爻，不得」「三合局而生应爻，不得」（R-ZS-QM-01）；出现无情（R-QIUMING-17、R-BZZ-QM-07）。父发者，录取一层仍可过，成行一层难（例 1）。
7. **子孙持世**：「休问功名」（R-QIUMING-10）。但父母发动来生合世的，录取一层可过，成行一层难（例 1），断语分两层写。
8. **兄弟持世而官不动**：「子孙兄弟持世，谋署谋差，自投罗网」（R-ZS-QM-03）；「官星不动，但遇兄弟持世……百无一成」（R-QIUMING-12；例 8）。官动制兄、或父官两动者不论（R-ZS-QM-12）。
9. **六爻乱动**（四爻以上发动）（R-QIUMING-10）。
10. **子孙局成**；**兄局成而世在局**，又无日月生扶或官不旺（R-SANHE-05、R-SANHE-06）。
11. **官无可用**：官不上卦、伏而不出、又无化出；或官无力而父母也不发动。

### 3. 能过：没有否决，任一条成立，判有望（能过）

1. 旺官持世（R-YONG-GUAN-03；R-QIUMING-10「若非旺父生身，定是旺官持世」）。月日相敌的官持世不算旺（R-YUEJIAN-04；例 5）。
2. 旺官生合世，或日月作官星生合世（R-QIUMING-08、R-YONG-GUAN-03）。
3. 旺父持世、生合世，或伏于世下，而官有气（R-QIUMING-03「父爻持世……亦要官星有气」）。
4. 官父两旺（R-QIUMING-15、R-QIUMING-14；例 7）。
5. 父母发动而生合世，或化出之爻合世：官衰父发，亦论抡收（R-QIUMING-03；例 1）。
6. 官局、父局成而世在局（R-SANHE-05「二合无冲」）。
7. 应爻发动生合世，官父有气：必资鹗荐（R-QIUMING-09）。

### 4. 都不成立时

官旺：有望而待时。官不旺：偏难；父旺而官不旺的，按「父旺官衰终须下第」（R-QIUMING-08；例 5）。

### 5. 卦级

六冲卦：官父世俱旺者仍许（R-QIUMING-14）；不俱旺者，能过降为待时。六合卦：要官父世得地，有一失陷而无生扶，六合无益（R-QIUMING-14；例 6）。

### 6. 应期

通知、放榜看父母（R-QIUMING-16）；录取看官星，按 docs/09。两者不同时，分开写。

## 〇、2026-11-15 修订（eq-0.13，优先于下文各节）

起因：古籍功名卦例检验（`reports/case-validation-interview-2026-11-15.md`）中，18 例错 7 例，错处集中在下列条目。下文一至五节凡与本节冲突的，以本节为准。原文均出《增删卜易》（`sources/classics/增删卜易.md`，行号为该文件行号）。面试属「求名」，用功名诸章（乡试章、升选候补章），不用谒贵章「世克官，官生世，须宜谒见」（觉子：「切勿以此得见贵人之官星换作成名而断也」，L2851）；此取舍记为 D-021。

1. **官星须有情于世（新增，出现无情）**。乡试章 L2558：「出现无情﹐难遂青云之志。父与官星虽则出现﹐若不生合世爻﹐或不持世﹐或世爻空破﹐或被世爻冲克﹐亦属无益。父与官星生合世爻﹐若又被日月动爻冲坏者﹐亦作无情之谕。」升选候补章 L2599：「旺官持世及日月动爻作官星生合世爻﹐或世爻发动化出官星生世皆吉。」
   - 有情：官持世（含官鬼两现而另一爻持世，类键「官另爻持世」）；官生世、合世；日月作官星而生合世爻；世爻发动化出官星；官局成而世在局或局生世。
   - 无情：官不持世，又不生合世（世生官、比和、无生合、官只生合应爻）；世克官、世冲官。无情者判偏难（「亦属无益」），用神再有气也不翻。
   - 官克世：升选章 L2623「助鬼伤身﹐身衰者祸至……予屡试之﹐世旺者竞升﹐世衰者不吉。助鬼伤身﹐元神同动者﹐其官必升」。世爻有气或元神同动者按有情论；世爻无气者判偏难。
2. **令星不受伤（修订「忌神动而有力一律偏难」）**。黄金策「爻遇令星，物难我害」（增删 L1286 引，「日辰月建章注解极明」）；升选章「官临日月必超迁」（L2599）；月将章 L339「爻值月建，墓于日或日建冲克者可以敌之，无吉无凶之象……恐他爻又来克制用神，虽临月建，亦难敌也」。
   - 官临日辰：忌神发动、暗动伤它不到。
   - 官临月建而日辰不冲克它：忌神发动、暗动伤它不到。
   - 官临月建而日辰又冲克，再加动爻来克：从 L339「亦难敌」，按原规则。
   - 发动之忌神与他爻合成生官之财局（已成或待时）：月将章 L347「虽被申日冲克﹐喜申子辰合成水局﹐以生官﹐不独无害」，不以忌神论。
3. **子孙局（修订「子孙局成一律偏难」）**。原则不变（R-SANHE-05「合成子孙局者乃伤煞之神也」、R-SANHE-06「惟忌合成子孙局者﹐不为吉也」）；但日月作官星而生合世爻者，子孙局伤不到日月之官（R-RIZHEN-07「爻伤日徒受其名」，L1308；例：L1173「既临日建又得月令作官星而合世……至辰年官而出空一定高升」），不判偏难，按卦中官星之状态（空则待出空）定迟速。
4. **化出之官（修订「伏而难出一律偏难」）**。官不上卦而有动爻化出官星：以化出之官为用（升选章「世爻发动化出官星生世皆吉」；例 L2786「内卦寅木父母旺而化出子水之官﹐许寅年仍以原品起用」）。世爻化出官者吉；他爻化出官而生合世者吉；化出之官休囚空破或不生合世者，从第 1 条无情论。
5. **世破被克（新增）**。援例章例 L2683：「财动生官﹐不宜世临月破﹐破而被克者﹐有官不能享也。」世爻月破又受日克或动爻克者判偏难；世破有气而不受克者仍按原文作待时。
6. **财空（D-022，收窄 D-018）**。署印谋差章「财与官星不可有一而不旺……世陷财空﹐不如守己」（R-SHUYIN-01）。面试只在世陷（世空或世破）而原神妻财旬空（类键「原待时(旬空)」「原空无力」）时据此判偏难；财静而无力、财待时、财伏者不另翻判（卦例：增删 51/20#4 旺官持世而财无力，亥月升；50/6#4 官临日建持世，卯月升）。

## 二、忌神（子孙）、原神（妻财）

- **忌神**：
  - 忌神与元神同动：用神有根者，「忌神虽动，不能克用神者…忌神与元神同动七也」（R-YUANJI-04），接续相生，化凶为吉；用神无根者，「元神有力亦难生」（R-YUANJI-06 原例），仍判不利（IPC-0298、IPC-0308）。
  - 用神有气而旬空（`[DEFERRED旬空]`）、忌神与元神皆动而有力者：接续相生成立，眼下待出空，判眼下悬而未决、出空后有望（IPC-1027）。
  - eq-0.12.4 起，忌神「动有力」而原神最强一爻不是发动之爻、另有一爻原神发动时，类键加「忌元同动(原…)」，括号内是发动之原神自身的作用状态。原键未分此项，IPC-0241、0386、0408、0467、0480、0481、0485、0503、0519 及第 569 类曾把同动与不同动之盘并在一类；拆分后各按新类内容改稿。同动而发动之原神旬空待时者，从 IPC-0480 之理判有望而待时；原神静而另无同动者，从八宫图「被卦中子孙发动以伤官」判偏难。
  - 「动有力」「暗动有力」为主要不利依据（C22）。
  - 「静旺有力」只能克休囚之爻（R-DONGJING-01）。忌神旺相时，月建必为子孙或兄弟之五行，官星必休囚，所以静旺之忌神总能克到官星，属不利，但弱于发动。
  - 「伏有效」作潜在不利，不作主要依据。
  - 「伏待时」「伏难出」「静不作用」「无力」「待时（旬空）」不构成威胁。
  - 忌神发动而化回头克、化绝：本属「忌神虽动，不能克用神者」之列（R-YUANJI-04）；但所化之忌神得月建、日辰或他爻动来生扶合助者，依野鹤「化绝…临日月帮助，亦无大害」（R-HUA-03）类推，克力未断，仍判有力（IPC-2105、IPC-2177、IPC-2303）。无扶者按七不克处理（IPC-1047、IPC-2188）。
  - 待核：引擎对「静用受判为无力之动子孙所克」时仍常判用神无力（含当令临日之官，如 IPC-2138、IPC-2254），与七不克第一、五、六条有张力。同型类暂按先例判偏难，正文以序「子孙动于卦中」为据、不写「子孙无力也能克」之类断语；待另行核对引擎。
- **原神**：
  - 「动有力」为最强之助（「财动生官得美缺」，R-YONG-GUAN-03）。
  - 「静旺有力」只对休囚之官有生扶之用；官星不休囚时不另计（IP-0002、IPC-0003 之例）。
  - 「伏有效」为一线转机，不作翻判依据（D-013）。
  - 其余不计。
- **原忌皆静而旺相**（月建为子孙之五行）：克者旺于生者，「克用神之神旺相者可以凶推」（R-SICHU-01）。

## 三、世爻

- **持世**：见上。
- **世安**：不另计。
- **世受克**：「世爻受制，岂宜自己之谋」（R-SHIYING-03），为次要不利。
- **世空、世破**：
  - 「世空世破官破官空，俱不得」（R-YONG-GUAN-07）；「官空世破，且让他人」（R-YONG-GUAN-04）。
  - 世破一般判偏难。
  - 世空：类推 D-017 的口径，世爻有气而空者作待时，无气而空者从「俱不得」。
    - eq-0.12.2 起指纹把世空分为「世空有气」（世爻三层判定非无力，作待时）与「世空无气」（世爻三层判定无力，从「俱不得」），同类之内不再混杂。
  - 世破：月破之论依野鹤（D-006）「目下虽破，出月则不破」，正文须写明破只管当月；类内世爻有气、无气混杂时仍从专章判偏难。
  - 世破而世爻全类有气（三层判定待时，非「静而不动又无日辰动爻生助」之到底破，R-YUEPO-02）者，类推世空有气，作待时（有望而待时），正文写明出月、填实、逢合之日可复（IPC-0304 起）。
  - 结论以「世空世破」为主要不利依据时，判断记录写 `decisive: [{role: world, effect: adverse, basis: 空破}]`（C33 逐盘核对世爻确空或确破）。
- **世…子孙（子孙持世）**：「子孙持世且待时」（八宫图）、「子孙持世，休望荣荫」（升选章）、「子孙持世而失望」（序）。
  - 忌神有力时判偏难。
  - 忌神无力时，从八宫图「且待时」判待时；类推，正文须写明「持世的子孙本身无力」。
- **世化吉、世化凶、世动**：
  - 「世化退神…必无勇往之心」（乡试章，R-SHIHUA-01）：化凶为次要不利。原文只言化退；化回头克、化绝、化墓为程序类推，正文须分别说明。所化兼回头生与化绝者（如土化巳火），吉凶相杂，只作次要因素。
  - 化吉为次要有利。
  - 世动：主动之象，不另计吉凶。

## 四、卦级

- **六合**：「凡得诸合，诸占皆以为吉」，但须用神有气，且官父世得地（R-HE-01、R-HE-02）。用神有气时加强有利；用神无力时「虽六合亦无益」。
- **六冲**：「冲者散也…占吉事而不宜，必兼用神而言，用神旺虽冲不破，用神失陷凶而又凶」（R-CHONG-01）。
  - 用神有气：结论不翻，但须写明事有散意、易生波折。
  - 用神无力：加重不利。
- **变合**（六冲卦变六合）：「占功名始则艰驻，终顷荣显」（六合章，底本如此，「驻」「顷」疑为「阻」「倾」）。其余变出六合者，作后段有合之象。
- **合变冲**：「先合后离…始荣终悴，得而复失，成而后败」（六合章、六冲章），为后段不利。
- **反吟、伏吟**：反复、迟滞（R-FANFU-01）。用神旺相不变冲克者「虽则反复，事之必成」。

## 五、三合局

按 D-020 与 R-SANHE-01..06，见 docs/06。吉局待成者，取 R-SANHE-03/04 作待时之期；凶局作防范之时。

- 子孙局已成：不论单爻子孙是否有力，判偏难（「合成子孙局者乃伤煞之神也」，R-SANHE-05；IPC-2089、IPC-2103）。
- 官局已成而世在局：大势从「合成官局谓之官旺」「必要世爻在局为美」（R-SANHE-05）；但用神自身化墓或化回头克（自化有困）者，判有望而待时（IPC-0911、IPC-2311 第 2 版）。官局已成而用神不化凶者判倾向通过（IPC-0887、IPC-1306）。

## 六、应期

只写**全类每一盘都有候选**的规则（`reports/class-profiles-*.json` 的 timing_rules_all_charts）。没有全类通用的规则时，应期栏只写说明、不列条目（docs/09「没有依据时应期栏可以只写说明」），不得写出只对部分盘成立的日子。

## 七、结论类别

| 类别 | 何时用 |
|---|---|
| 倾向通过（likely-pass） | 用神有气且无有力之克，或有原神动生 |
| 有望通过但要待时（pass-but-slow） | 有利而有明确的慢因：休囚化进神、伏而有用、子孙持世而无力、六冲有散意等 |
| 悬而未决，待时有望（wait-then-likely） | 用神有气而旬空、伏而待时 |
| 偏难通过（unlikely） | 用神无力、伏难出、化凶，或忌神有力而克，或世破、子孙持世而忌神有力 |
| 成败未定（undetermined） | 有利、不利证据势均而无规则可定者；须写明理由，慎用 |
