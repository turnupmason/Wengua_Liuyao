# 07 月建日辰、旬空、月破和旺衰

> 代码：`src/calendar.js`、`src/analysis.js`。

## 一、历法

| 项 | 口径 | 实现 | 核验 |
|---|---|---|---|
| 日干支 | 起卦者当地民用日 | 儒略日纯算法：(JDN + 49) mod 60，2000-01-01 为戊午 | 1900-01-01 至 2100-12-31 每天与 lunar-javascript 一致；锚点 1949-10-01 甲子 |
| 月建 | 以十二「节」交接为界，不按公历月份（R-YUEJIAN-01） | 随包节气表 `src/data/jie-table.js`（2415 个交节时刻，UTC 秒），由 lunar-javascript@1.7.7 生成，可由调用方注入 | 与独立的 Meeus 太阳视黄经算法比对：最大差 13.8 分钟、平均 4.1 分钟（即该算法自身精度） |
| 年干支 | 以立春为界（太岁，本版不参与断语匹配） | 同上 | 立春前后与公历跨年测试 |
| 旬空 | 依日干支所在之旬（R-KONG-01） | 纯算 | 六十甲子全部与「甲子旬中戌亥空」六句一致 |

时区与换日：

- 起卦瞬间按调用方传入的 IANA 时区换算民用日（默认 Asia/Shanghai）。**主应用必须传设备当地时区**；同一瞬间在上海与纽约可以是不同的日辰（已测试）。月建以交节瞬间为界，与时区无关。
- 子时换日默认 0 时（`midnight`），可选 23 时（`zi-hour-23`）；23 时起卦一律给出 `zi-hour` 提示。古籍未见明文，列为分歧 D-009，待用户确认。
- 距交节不足 30 分钟起卦给出 `near-jie-boundary` 提示：节气表精度无法用独立算法确认到分钟级。

## 二、旺衰（R-WANG-01、R-WANG-02）

- 四时旺相（增删卜易·四时旺相章）：与月建同五行为**旺**，月建所生为**相**，其馀为**休囚**；未月火、丑月水有**馀气**。不另设「死」级，不设任何数值倍率或成功率。
- 广义之旺（题头总注）：临日月、得日月动爻变爻生扶、长生帝旺于日，皆谓之旺。程序同时输出狭义（`seasonalStrong`）与广义（`strongBroad`），断语须说明用的是哪一种。
- 旺衰、月破、旬空、入墓是不同维度，分别输出，不互相折算。

## 三、月建、日辰对各爻（`calendarFacts`）

每爻（含变爻、伏神）输出：临月建/月扶/月生/月克/泄/耗/月合/月破/月刑；临日/日扶/日生/日克/日合/日冲/日刑；日上长生、帝旺、墓、绝。

## 四、月破（R-YUEPO-01、R-YUEPO-02，分歧 D-006）

月建所冲为月破。采用野鹤之说：月破之爻发动仍能伤爻；破只在本月，出月、填实、逢合之日可复；静而又无日辰动爻生助者才是到底之破。诸书「枯根木」之说同列。

## 五、日冲（R-RIZHEN-02/03/04、R-ANDONG-01，分歧 D-001、D-012）

| 情形 | 增删卜易（采用） | 卜筮正宗（同列） |
|---|---|---|
| 静爻、不空、旺相（四时旺相或得月合）逢日冲 | 暗动 | 暗动 |
| 静爻、不空、休囚逢日冲 | 日破 | 暗动 |
| 旬空之爻逢日冲 | 冲空则实 | 静空冲起、动空填实 |
| 动爻逢日冲 | 旺相者不散；休囚者间有冲散（百中一二） | 冲散（冲脱） |

休囚静爻得他爻动生而逢日冲如何论，书中未见明例（D-012）。核验中曾据暗动章「坤之师」一例误以为广义旺即可暗动，复查发现该例丑土在甲寅旬空，书中「冲动」实为冲空则实，已改回四时旺相或月合。

## 六、旬空（R-KONG-02..06，分歧 D-002）

| 程序结论 `void.zengshan` | 条件 |
|---|---|
| 冲空则实 | 日辰冲空爻 |
| 空而又破 | 旬空又月破 |
| 真空 | 静、休囚，且为春土、夏金、秋木、冬火 |
| 旬内暂空，出旬可用 | 旺相、发动、得日辰或动爻生扶、伏而旺相 |
| 静空无助 | 以上皆不合 |

依增删卜易月将章「在旬内者毕竟为空」，「出旬可用」不等于眼下有用。黄金策「自空化空，必成凶咎」「无故勿空」同列于 `void.huangjince`。空的种类另分静空、动空、化空、伏空。
