# 02 六十四卦八宫归宫与世应

> 规则：R-BAGONG-01、R-SHIYING-01、R-SHIYING-02、R-YOUGUI-01、R-GUA-CHONGHE-01/02（见 `rules/register.json`）。代码：`src/hexagrams.js`。

## 归宫算法

1. 每宫首卦为八纯卦（上下同为本宫经卦），世在上爻。
2. 自初爻起逐爻变：变初爻为一世卦、再变二爻为二世卦……变至五爻为五世卦；世爻即所变到的那一爻。
3. 五世卦复变第四爻为**游魂**卦，世在四爻。
4. 游魂卦内卦（下三爻）复归本宫经卦为**归魂**卦，世在三爻。
5. 应爻与世爻相隔两位（世一应四、世二应五、世三应六，反之亦然）。

六亲以**本卦所属卦宫**的五行为「我」，不以上下卦计算。

## 独立核验（`tests/palaces-najia.test.mjs`）

- 与《卜筮正宗·十四、六十四卦名》原文逐宫逐序一致（原文离宫三世误作「水火未济」，按校勘 C-004 读作火水未济）。
- 用另一套口诀独立推算：**寻世诀**「天同二世天变五，地同四世地变初，本宫六世三世异，人同游魂人变归」与**认宫诀**（一二三世与本宫看外卦、四五世与游魂看内卦三爻全变、归魂看内卦），64 卦全部与算法结果一致。
- 六冲卦恰为《增删卜易·八宫图第三》所列十卦；六合卦为八卦（否、泰、困、节、旅、贲、复、豫）。
- 《增删卜易》182 个书中印出的卦盘，世应位置与本算法逐一相符（`tests/classical-charts.test.mjs`）。
