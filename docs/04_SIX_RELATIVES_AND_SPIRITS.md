# 04 六亲与六神规则

## 一、六亲（R-LIUQIN-01）

以**本卦所属卦宫**五行为「我」：

| 关系 | 六亲 |
|---|---|
| 生我者 | 父母 |
| 同我者 | 兄弟 |
| 我生者 | 子孙 |
| 我克者 | 妻财 |
| 克我者 | 官鬼 |

卦宫五行：乾、兑属金；坎属水；艮、坤属土；震、巽属木；离属火（卜筮正宗·八宫所属缺离，见校勘 C-006）。

六亲是传统的关系与事项分类符号，不等于现实人物。同一个官鬼爻，求职时代表职位与录用方，疾病时代表病，官司时代表官府；同一个妻财爻，在求职中是生官的原神，不能一律解释为得钱。具体含义只在每个问事的用神规则表（`src/questions/`）中定义。

伏神（R-FUSHEN-01）：本卦缺某类六亲时，取本宫首卦（八纯卦）同位之爻为伏神，伏于本卦该爻（飞神）之下；伏神的六亲同样按本卦卦宫推。八纯卦五类六亲俱全（已测试）。

## 二、六神（R-LIUSHEN-01）

依起卦日**天干**定初爻，再按 青龙→朱雀→勾陈→螣蛇→白虎→玄武 往上排：

| 日干 | 初爻 |
|---|---|
| 甲、乙 | 青龙 |
| 丙、丁 | 朱雀 |
| 戊 | 勾陈 |
| 己 | 螣蛇 |
| 庚、辛 | 白虎 |
| 壬、癸 | 玄武 |

六神只作象意辅助（R-LIUSHEN-02：「虎兴而遇吉神，不害其为吉。龙动而逢凶曜，难掩其为凶」）。断语中不得单凭青龙断吉、白虎断凶、玄武断盗；本轮六篇样稿未以六神作任何判断依据。

## 三、月卦身（参考）

卜筮正宗有安月卦身诀，增删卜易称「试之不验」（分歧 D-008）。程序计算月卦身仅作参考事实（`chart.monthBody`，`status: reference-only`），不参与判断。

## 四、核验

- 六亲与《增删卜易·六亲歌章》原文逐宫解析比对一致。
- 六神与《卜筮正宗·六兽歌》《六兽起例》一致，十天干全部覆盖。
