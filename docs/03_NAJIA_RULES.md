## 二、变卦装卦

- 只有发动之爻（老阳 9、老阴 6）发生阴阳变化；全部动爻变后得变卦。
- 变爻的干支取**变卦同位之爻**的纳甲。
- 变爻的六亲按**本卦卦宫五行**推（增删卜易·动变章「变出之爻安六亲者仍照正卦而推」；八宫图第三泽天夬变天风姤，丑、戌二土照夬卦写兄弟）。程序同时保存按变卦自身卦宫推出的六亲（`relativeInChangedPalace`），只供对照，不参与判断。
- 静爻没有变爻。判断内外卦反吟、伏吟时，比较的是本卦与变卦**整个经卦**的纳支（静爻在变卦中取变卦纳甲），见增删卜易·反伏章「比之井」。

## 三、计算证据

每张卦盘输出：本卦与变卦的卦码（初→上 0/1）、卦名、上下卦、卦宫及五行、世应、每爻天干地支五行、六亲、六神、动静、变爻干支六亲、伏神及来源（如「巽为风三爻」），并由 `chartKey`（六爻值 + 月建 + 日辰）唯一确定。

## 四、核验

- 纳支、纳干与《卜筮正宗·纳甲装卦歌》原文逐卦解析比对一致；与《增删卜易·浑天甲子章》互校一致（含校勘 C-002）。
- 4096 种本卦×动爻组合中，每个变爻的干支都等于变卦同位纳甲，六亲照本卦宫。
- 《增删卜易》182 个书中卦盘：本卦六爻六亲地支、变爻六亲地支逐爻一致。
